Fix "App Cannot Be Installed" on Pixel

Why Pixel said "App cannot be installed":

When you tap Install, Google's Android WebAPK server connects to nicholaswguidry.github.io/monocast/ from the cloud to download manifest.json and sw.js. It rejects fake data: or blob: URLs hidden inside a single HTML file.

Option 1: Instant Fix (0 Extra Files Needed) 10 Seconds

Tap Chrome's three dots (⋮) → Add to Home screen. When the popup asks between Install and Create shortcut, tap "Create shortcut"!

Because this page includes mobile-web-app-capable="yes", Create shortcut still launches in 100% fullscreen standalone app mode with no Chrome address bar!
